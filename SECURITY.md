# PELLAIRI PEDS Security Policy

## Supported versions

The `main` branch is the supported development version. No tagged releases are currently declared as supported.

## Report a vulnerability privately

Please use GitHub's **Report a vulnerability** form on the repository's [Security Advisories page](https://github.com/Geniehinge/pre-execution-decision-sandbox/security/advisories/new).

Do not disclose suspected vulnerability details in public issues, discussions, pull requests, or social posts. If the private form is unavailable, contact a repository owner or organization administrator to arrange a private reporting route. Do not send exploit details until a private channel is agreed.

Please include the affected file or component, the impact you observed, and steps to reproduce when safe. Do not include passwords, access tokens, personal data, or unrelated third-party information.

## Response expectations

The maintainer aims to acknowledge a report within seven calendar days and provide an initial assessment within fourteen calendar days. These are response targets, not a guarantee of a fix or release by a specific date. If a report is not acknowledged, please follow up using the same private channel.
